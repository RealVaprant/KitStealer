# Kit Stealer

Kit Stealer is a client-side Fabric mod for saving, organizing, and loading reusable Minecraft player inventory kits.

## Features

- Save a copy of the current player inventory as a named kit.
- Select kits with standard, Shift, Ctrl, and Ctrl+Shift click behavior.
- Load a selected kit into the player inventory while in Creative mode.
- Delete one or multiple kits with confirmation.
- Reorder kits with right-click dragging or `Ctrl+Shift+Up` and `Ctrl+Shift+Down`.

## Installation

1. Install Fabric Loader for Minecraft 1.21.11.
2. Install the required Fabric API version.
3. Place the Kit Stealer jar in the `.minecraft/mods` directory.
4. Launch Minecraft with the Fabric profile.

## Usage

The menu opens with `K` by default. The key can be changed under Options -> Controls -> Inventory.

### Selection

| Input | Behavior |
| --- | --- |
| Left-click | Select only the clicked kit |
| Shift + left-click | Select the range from the last selection anchor to the clicked kit |
| Ctrl + left-click | Toggle one kit without clearing the other selections |
| Ctrl + Shift + left-click | Add the range from the selection anchor to the clicked kit |
| Up / Down | Move the active selection through the list |
| Ctrl + Shift + Up / Down | Move the active kit up or down in the list |
| Right-click drag | Reorder the active kit |

Multiple selected kits are highlighted together. Loading is available only when exactly one kit is selected and the player is in Creative mode.

## Storage

Kit files are stored in:

```text
.minecraft/config/kitstealer/kits/
```
Each kit is saved as an individual JSON file.
